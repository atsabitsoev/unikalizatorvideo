# Уникализатор видео для Instagram (macOS)

Правый клик по видео в Finder → **«Уникализировать»** → рядом появляются 20 копий.
Окон и настроек нет.

Каждая копия получает свой случайный набор мелких изменений. При обычном
просмотре их не видно, но для алгоритмов поиска дубликатов это уже другое видео:
меняется геометрия кадра, скорость, цвет, звук и сам файл.

```
Отпуск.mp4  →  Отпуск_uniq_01.mp4
               Отпуск_uniq_02.mp4
               …
               Отпуск_uniq_20.mp4
```

## Установка

Нужна современная macOS (Monterey 12 или новее), Intel или Apple Silicon. Откройте **Терминал** и выполните:

```bash
git clone https://github.com/atsabitsoev/unikalizatorvideo.git
cd unikalizatorvideo
bash install.sh
```

Если скачали архив ZIP с GitHub, распакуйте его и выполните
`bash install.sh` в распакованной папке. Можно и двойным кликом по
`Установить.command`. Если macOS не даёт открыть файл, кликните по нему правой
кнопкой и выберите «Открыть».

Установщик делает три вещи:
1. Копирует скрипт в `~/Library/Application Support/Unikalizator`.
2. Если ffmpeg ещё не установлен, ставит его: скачивает готовую сборку в ту же
   папку (около 80 МБ). Homebrew и пароль администратора не нужны.
3. Добавляет пункт «Уникализировать» в контекстное меню Finder.

## Как пользоваться

1. Правый клик по `.mp4` или `.mov` → **Быстрые действия** → **Уникализировать**.
   На некоторых версиях macOS пункт стоит прямо в конце меню.
2. Пока идёт работа, в строке меню крутится шестерёнка. Через неё же процесс
   можно остановить.
3. По окончании придёт уведомление и прозвучит сигнал. Копии лежат рядом с исходником.

Можно выделить сразу несколько видео: каждое получит свои 20 копий.
При повторном запуске старые копии не перезаписываются, нумерация продолжается
(`_uniq_21`, `_uniq_22`, …).

**Сколько это занимает:** на Mac с Apple Silicon 20 копий 30-секундного ролика
должны делаться примерно за 2–4 минуты. Это оценка по замерам фильтров, на
реальном Mac время не измерялось. Кодирует аппаратный VideoToolbox, несколько
копий идут параллельно. С `ENCODER=x264` выходит примерно втрое дольше.

При первом запуске macOS может спросить, разрешить ли доступ к папке
«Загрузки», «Рабочий стол» или «Документы». Нажмите «Разрешить».

## Что именно меняется

Для каждого параметра диапазон делится на 20 частей, и каждая копия берёт
значение из своей части. Сдвиг и поворот кадра подбираются так, чтобы копии были
как можно дальше друг от друга. Поэтому копии отличаются не только от оригинала,
но и между собой.

| Что | Как (сила `normal`) | Зачем |
|---|---|---|
| Кадр | зум 5–8% со сдвигом рамки, поворот 0.1–0.35°, лёгкая перспектива | главное средство против перцептивных хешей (см. ниже) |
| Время | скорость ±1.5–3% (тон голоса сохраняется), обрезка 0.02–0.12 с в начале и до 0.25 с в конце | сбивает покадровое и временное выравнивание |
| Цвет | яркость ±1–2%, контраст и гамма ±2–4.5%, насыщенность ±3–7%, оттенок ±1–3° | меняет цветовую статистику |
| Свет | едва заметное плавное «световое поле», ±2.5–4 уровня яркости из 255 | у каждой копии свой рисунок |
| Детали | лёгкое зерно, кадр чуть резче или мягче | меняет мелкую текстуру |
| Звук | высота тона ±0.5–1.2%, громкость ±0.2–1 дБ, два полосовых эквалайзера, срез ниже 20–45 Гц и выше 16.5–19 кГц, 44.1 или 48 кГц | против аудио-отпечатков |
| Файл | полное перекодирование H.264 + AAC, удалены все метаданные и подписи ffmpeg/x264 | другой файл и другой хеш |

Сдвиг рамки подбирается по замерам: для PDQ (см. ниже) 1% сдвига кадра даёт
около 22 единиц расстояния, 1% зума — около 9, поворот на 1° — около 18, а цвет,
шум и перекодирование почти ничего (1–8). Поэтому для каждой копии из
300 случайных вариантов геометрии выбирается тот, что дальше всего и от
оригинала, и от уже сделанных копий.

Разрешение сохраняется. Видео больше 1080 по короткой стороне (например, 4K)
уменьшается до 1080: Instagram больше не показывает. HDR с iPhone переводится в
обычный SDR. Видео с телефона, снятые повёрнутыми, обрабатываются правильно.

## Насколько это работает

Проверено на **PDQ**. Это открытый алгоритм Meta (Instagram — продукт Meta) для
поиска одинаковых картинок. На нём же построен их видеосопоставитель vPDQ.
Два кадра считаются одинаковыми, если расстояние между хешами не больше 31 из 256.
Видео считается копией, если совпала большая часть кадров.

Замер: вертикальный ролик 1080×1920 из трёх сцен открытых фильмов (Sintel,
Big Buck Bunny, Jellyfish), 2 кадра в секунду, порог 31.

| Что сделали с видео | Совпало кадров с оригиналом |
|---|---|
| только перекодировали | 100% |
| только цвет, только шум или только «световое поле» | 100% |
| только зум 4% по центру | 43% |
| **копии уникализатора** (`normal`, 20 штук) | **в среднем 1%, у худшей копии 17%; у 17 из 20 — 0%** |
| **копии между собой** (190 пар) | **в среднем 3%, у самой похожей пары 52%** |

Проверить свои копии можно так:
```bash
pip3 install numpy pdqhash
python3 tools/check_uniqueness.py видео.mp4 видео_uniq_*.mp4
```

**Честно о границах.** Гарантировать, что Instagram посчитает видео уникальным,
не может ни один уникализатор. У Meta кроме PDQ есть и закрытые системы:
нейросетевые «отпечатки», устойчивые к небольшим правкам, распознавание музыки,
сигналы аккаунта. Изменения, незаметные человеку, по определению малы.
Уникализатор выжимает из них максимум против известных алгоритмов, но не обещает
обойти всё. Если нужно сильнее, есть сила `strong` и зеркалирование (см. ниже),
но их уже можно заметить.

## Настройки

```bash
open "$HOME/Library/Application Support/Unikalizator/settings.conf"
```

| Параметр | По умолчанию | Значение |
|---|---|---|
| `COUNT` | `20` | сколько копий делать |
| `STRENGTH` | `normal` | `light` — минимум изменений, `normal` — оптимум, `strong` — сильнее |
| `MIRROR` | `0` | `1` — зеркалить каждую вторую копию (заметно на тексте и логотипах) |
| `SUBFOLDER` | `0` | `1` — складывать копии в папку «имя_uniq» рядом с видео |
| `ENCODER` | `auto` | `auto` — VideoToolbox (быстро), `x264` — программный (медленнее) |
| `JOBS` | `auto` | сколько копий кодировать одновременно |
| `MAX_SIDE` | `1080` | максимум для короткой стороны кадра |

Изменения действуют со следующего запуска, перезапускать ничего не нужно.

## Из Терминала

```bash
UNIK="$HOME/Library/Application Support/Unikalizator/unikalizator.sh"
"$UNIK" видео.mp4                        # 20 копий рядом с видео
"$UNIK" -n 5 -s strong видео.mp4         # 5 копий посильнее
"$UNIK" -o ~/Desktop/копии *.mp4         # все mp4 из папки, копии на рабочий стол
"$UNIK" --help
```

## Если что-то не так

- **Нет пункта в меню.** Системные настройки → Конфиденциальность и безопасность →
  Расширения → Finder (или «Добавленные расширения») → включите «Уникализировать».
  Если не помогло, перезапустите Finder: ⌥ + правый клик по значку Finder в Dock →
  «Перезапустить».
- **Ничего не происходит / ошибка.** Посмотрите журнал:
  `open ~/Library/Logs/Unikalizator.log`.
- **«Не найден ffmpeg».** Запустите `bash install.sh` ещё раз.
- **Обновление.** `git pull && bash install.sh` в папке проекта. Настройки сохранятся.

## Удаление

```bash
bash uninstall.sh
```
Можно и двойным кликом по `Удалить.command`. Удаляются пункт меню, скрипт,
настройки и скачанный ffmpeg. Ваши видео не трогаются.

## Разработчикам

- `unikalizator.sh` — всё ядро: bash 3.2 (как в macOS) + awk + ffmpeg.
- `workflow/Unikalizator.workflow` — быстрое действие Automator, которое вызывает скрипт.
- `tests/smoke_test.sh` — проверка на синтетических видео (macOS и Linux):
  `bash tests/smoke_test.sh`.
- `tools/check_uniqueness.py` — замер уникальности по PDQ.
